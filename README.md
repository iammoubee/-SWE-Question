### Question 1: Design Fundamentals & Object-Oriented Quality Metrics [14 Marks]

* **(a) [4 Marks] — [CO1 | Bloom's: Knowledge (C1)]**  
  State the **two** basic steps of the software design process and identify the key output artifacts (including why design rationale is recorded) produced at the end of the design phase.

* **(b) [5 Marks] — [CO1 | Bloom's: Understanding (C2)]**  
  Explain why software engineers aim for **low coupling** and **high cohesion** when decomposing a system into modules. Distinguish clearly between *data coupling* and *control coupling*, and between *functional cohesion* and *coincidental cohesion*.

* **(c) [5 Marks] — [CO2 | Bloom's: Understanding (C2)]**  
  Explain what the **Lack of Cohesion of Methods (LCOM2 and LCOM3)** metrics measure in an object-oriented class. Interpret what a value near `0` indicates, and explain conceptually why an **LCOM3** value greater than `1` signals the presence of *dead attributes*.

---

### Question 2: Software Architecture & Design Patterns [18 Marks]

* **(a) [4 Marks] — [CO3 | Bloom's: Knowledge (C1)]**  
  List any **four** software architectural styles covered in the course (from *Layered*, *Event-Based*, *Model–View–Controller*, *Blackboard/Repository*, and *Pipes and Filters*) and state the primary structural components of each.

* **(b) [5 Marks] — [CO3 | Bloom's: Understanding (C2)]**  
  Compare the **Event-Based** architectural style with the **Pipes and Filters** architectural style, explaining how components interact, share data, and maintain independence in each style.

* **(c) [5 Marks] — [CO4 | Bloom's: Understanding (C2)]**  
  Explain the structural difference between the **Strategy** pattern and the **Template Method** pattern in handling algorithmic variations, and describe **one benefit** and **one liability** of each.

* **(d) [4 Marks] — [CO4 | Bloom's: Understanding (C2)]**  
  When mapping an object-oriented inheritance hierarchy to a relational database, explain how **Single Table Inheritance** differs from **Class Table Inheritance**, highlighting one key trade-off (such as query joins, storage space, or schema refactoring impact) for each.

---

### Question 3: User Interface (UI) Design & Accessibility [8 Marks]

* **(a) [4 Marks] — [CO5 | Bloom's: Knowledge (C1)]**  
  List **four** fundamental UI design principles (e.g., *learnability*, *user familiarity*, *consistency*, *minimal surprise*, *recoverability*, *user guidance*, *user diversity*) and identify **two** standard UI interaction modalities.

* **(b) [4 Marks] — [CO5 | Bloom's: Understanding (C2)]**  
  Explain how a user interface designer should use color and visual cues to present information effectively to users with **color vision deficiencies (color blindness)**, including why relying on color alone or red–green combinations should be avoided.
